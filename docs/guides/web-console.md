# Web 控制台

按 [项目首页](../../README.md) 启动后，打开 <http://127.0.0.1:8765>。默认本地目录是 `social-crawler-local/`，具体配置及优先级见 [配置指南](configuration.md)。控制台供受信任的操作者使用，账号配置可能展示本地 Cookie 和代理凭据。

## 账号与登录

在账号池创建小红书、RedNote 或抖音账号，配置独立浏览器目录和所需代理。小红书 / RedNote 可以选择 Chromium、AdsPower 或 Kameleo；抖音可以选择 Chromium 或 AdsPower。选择托管浏览器后，控制台会从可用的 Local API 自动读取 profile 列表并保存所选环境的稳定 ID，无需手工复制。已绑定其他账号和当前不兼容的环境不可选择。Kameleo 首版仅支持本机桌面 Chrome profile。不同站点不要共用 Cookie 或 profile。

点击“打开浏览器”进入当前账号窗口，保留已有登录。完成操作后点击“保存登录并关闭”，程序才验证身份并导出登录资料；失败时窗口保持打开。容器使用控制台内的 KasmVNC，本机未安装 KasmVNC 时使用原生浏览器窗口。页面停止发送心跳后约 120 秒，浏览器会话会自动关闭。

小红书 / RedNote 使用 AdsPower 或 Kameleo 的浏览器采集并选择“显示浏览器窗口”时，每个运行任务使用独立桌面。任务详情显示“观看采集画面”，账号池中的“打开浏览器”也会变为“观看采集”；查看画面只读，关闭页面不会停止任务。多个不同 profile 可以分别打开观看，同一 profile 仍保持独占。

账号列表不主动进行在线诊断。“已保存登录”只表示本地有资料；启用 / 禁用决定是否允许新任务分配。手动停用不会因登录成功自动启用。删除账号保留历史任务和本地会话文件。

同一账号、浏览器 profile 或冲突代理资源正在使用时，编辑、登录、浏览器查看与采集受资源占用保护。使用独立资源的其他账号仍可操作。

## 代理管理

在左侧「代理列表」添加代理名称、协议、主机、端口和可选的认证信息，然后在创建账号或账号详情的「使用代理」中选择。选择「本机直连」可解除绑定。列表展示连接地址与关联账号，不展示认证密码。

多个账号可以共用一个代理。修改连接信息会同步到所有关联账号；关联账号正在采集或打开浏览器时，需先结束使用再修改。删除前必须解除所有账号的绑定。复制账号时保留代理选择，浏览器目录与登录凭据仍各自独立。

升级后，账号已有的代理文件和环境变量会自动登记到列表，相同来源只登记一次，原有连接保持不变。编辑迁入代理的连接信息后，将改用控制台管理的私有文件。XHS / RedNote 的 AdsPower / Kameleo 浏览器和媒体下载直接使用其 profile 中的网络，浏览器模式无需在项目代理池重复配置。抖音 AdsPower 只用浏览器完成登录和 WebSign，`curl_cffi` 使用项目代理或直连；profile 未配置代理时项目也可保持直连，任务开始前会强制校验两边的出口 IP。

## 新建采集

在采集工作台点击“新建采集”，选择平台与来源：

- **关键词**：输入关键词，选择综合或最新排序及每词内容数。
- **指定帖子**：每行一个链接、分享文本或 ID，最多 100 个。帖子来源不执行关键词搜索。

设置每帖一级评论数量、展开的父评论数、每楼回复数，以及请求、时间、页数和请求间隔。数量达到本次目标不代表平台所有评论均已采完。“不限制评论数”仍受其他预算约束。

可以指定账号，也可以让系统从同平台账号池中选择。开始采集前需配置 PostgreSQL 并保存登录。Web 账号首次采集时会在 HTTP 与浏览器出口一致后自动记录所选代理的实际出口，并为尚未配置的额度维度建立系统默认策略；用户可以随后在系统配置中覆盖默认值。指定账号不可用时，任务不会自动换号。

小红书 / RedNote 默认使用浏览器路径，也可选择 HTTPX 或 curl_cffi。HTTP 模式需要完整访问参数；优先粘贴含 `xsec_token`、`xsec_source` 的分享链接。没有参数时先尝试已有记录，仍缺失则记录该帖失败，不自动启动浏览器补采。浏览器路径可从实际页面请求取得上下文。

分享短链会在采集时展开，仅支持对应平台域名。重复指向同一帖子的链接只采集一次。无效或不可见的帖子单独标记失败；登录失效或遇到限流时停止任务。

## 定时、停止与恢复

新建采集可选择立即运行或保存定时计划。计划支持固定间隔、每日时间和五段 Cron，并保存时区、启停状态及下次执行时间。定时计划不固定账号，到点从相同平台账号池分配；错过多个周期时仅补一次。

任务详情展示阶段、数量、日志、停止原因和各输入状态。手动停止保留已提交页。恢复保留原始来源和目标，默认使用剩余预算，也可明确追加请求数或时间。重新创建任务用于改变范围或再次刷新内容；暂不支持只采集新增评论。

## 内容库与媒体

内容库支持按平台、正文、作者、来源、完整度、任务和日期等条件筛选，分页查看帖子及已保存评论。内容库展示最新记录，任务导出保留当次快照。

下载媒体默认关闭。开启后在取得详情时下载图片、音频与第一个视频编码版本，单文件上限 2 GiB；默认目录为 `artifacts/media/<platform>/<content_id>/`，可由 `CRAWLER_ARTIFACTS_DIR` 修改。下载失败单独记录，不影响已经保存的正文。

本地媒体优先用于预览；未下载时依赖平台 URL，其时效和访问限制可能影响展示。

## 分析与运行配置

帖子和任务详情提供分析入口，左侧 Agent 分析支持自由会话。建立会话不调用模型，点击发送后才调用。详见 [Agent 分析](agent-analysis.md)。

系统配置中的自动冷却默认关闭。开启后风险账号按错误等待，再进行有限恢复检查；登录失效时的 Profile 自动恢复是独立账号选项。无论这些选项如何设置，任务预算、额度和出口检查仍生效。

Cookie、代理与浏览器目录等账号字段，任务配置及全局环境变量分别维护，具体位置见 [配置指南](configuration.md)。开发者可从 [configs](../../configs/) 复制模板到 `config.local.toml`；帖子模板需要自行填入目标，代理文件也需自行准备。
