# 手动分析模块

分析模块通过 Claude Agent SDK 读取已采集的数据。用户发送消息时才调用模型，接口需兼容 Anthropic。

## 数据范围

[AnalysisService](../../src/social_crawler/analysis/service.py) 管理会话；[data.py](../../src/social_crawler/analysis/data.py) 将业务查询限定到会话范围。

| 入口 | 数据范围 |
| --- | --- |
| 帖子分析 | 该平台、该帖子及已保存评论和回复 |
| 任务分析 | 创建会话时冻结的任务数据与覆盖情况；后续采集不改变快照 |
| 自由分析 | 当前库内可查询的帖子、评论与任务 |

Agent 通过 `coverage`、`search`、`list_runs`、`run_data` 四个工具分页查询数据，并通过 `list_media`、`inspect_media` 查看帖子已下载的媒体。查询返回匹配总数，提供给模型的正文另存为证据版本；原数据更新后仍可查看当时的证据。

## 执行与权限

[agent.py](../../src/social_crawler/analysis/agent.py) 延迟加载 SDK。每个会话创建时固定一种执行模式：

| 模式 | 权限与用途 |
| --- | --- |
| 只读分析 | 只开放上述六个业务工具，禁用通用内置工具、项目设置和 Skills；不能启动采集、改数据库、执行 Shell 或读取任意本地文件 |
| 工作区 Agent | 使用 Claude Code 内置工具，加载用户、项目和本地设置及可发现的 Skills，以 `bypassPermissions` 在项目根目录自动执行工具和命令 |

工作区 Agent 是用户在新建会话时的显式选择，页面持续显示高权限提示，且会话创建后不可切换模式。它可以修改或删除工作区文件，因此默认仍为只读分析。

只读媒体工具仍执行范围校验，不向模型返回本地路径。图片经格式验证、旋转修正和缩放后传给模型；视频只以固定参数调用本机 `ffprobe`/`ffmpeg`，最多均匀抽取 12 帧，不执行媒体中的命令，也不包含音频转写。媒体必须已由启用“下载图片和视频”的采集任务保存到本地。

用户发送时锁定本轮配置并启动后台线程，消息与工具证据逐步保存。用户停止会中断本轮并保留已收到的内容。应用重启把遗留运行中的分析标记为中断，不自动发起下一次模型请求。SDK 会话 ID 和私有恢复目录用于用户之后主动继续对话。

## 配置与附件

模型设置按“页面保存值 → 环境变量 → 默认值”读取。密钥和 SDK 运行参数存于运行根目录 `data/web/agent-settings.json`，以 `0600` 权限原子写入，配置响应只返回是否已设置密钥。运行参数包括备用模型、轮次与费用上限、消息缓冲区、推理模式和推理强度；权限模式、工具范围和工作目录仍由程序固定。留空保存保留原密钥，保存本身不发起连接检查；用户可以主动执行一次无工具的短消息检测。

服务地址使用通用规则：允许服务根地址，也可从 `/v1`、`/v1/messages` 或 `/v1/chat/completions` 提取 SDK 根路径；路径形式不作为兼容性结论。仍拒绝含凭据、查询参数或片段的地址，实际兼容性由用户主动检测确认。

附件处理位于 [attachments.py](../../src/social_crawler/analysis/attachments.py)，保存在私有分析目录，并按会话验证访问范围。附件和查询出的正文均作为待分析数据；发送分析时，相应内容会传给所配置的模型服务。

分析可把用户设置的单轮费用上限交给 SDK 执行，但第三方模型的费用识别取决于兼容性，不做应用侧费用估算。备份时同时保留数据库、设置文件和 `data/web/agent/`，以保留证据、附件及 SDK 恢复记录。用户操作详见 [Agent 分析指南](../guides/agent-analysis.md)，测试见 [test_analysis.py](../../tests/test_analysis.py)。
